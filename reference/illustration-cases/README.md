# Оригиналы двух иллюстративных кейсов

Все 13 файлов в `assets/` сохранены без изменений из авторского архива `NPC_Dandelion_Dva_Keisa_TZ_i_Originaly_UPDATED_2026-10-16.zip`. Контрольные суммы сверены с `ASSET_MANIFEST.json` до и после копирования. `CONTENT.md` содержит предоставленные авторские тексты.

Страницы используют утверждённую обложку подкаста и её линейный эскиз, монтаж применения, декоративную полосу с рыбами, чистый эскиз девушки и последний утверждённый финал. Старые варианты, презентации и референсы сохранены здесь для истории; они не подменяют утверждённые оригиналы на страницах.

Производственные WebP лежат в `public/assets/illustration-cases/`. Квадратные иллюстрации оптимизированы без изменения композиции. Два небольших фрагмента девушки вырезаны из утверждённого финала без увеличения исходного разрешения.

- `/projects/za-predelami/` — нативный range, эскиз слева и финал справа; без JavaScript видны два изображения рядом.
- `/projects/devushka-s-maskoy/` — SVG clipPath с пятью асимметричными потёками, привязанный к обычной прокрутке. Без JavaScript и при reduced-motion показан статичный финал.
