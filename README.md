# NPC Dandelion — портфолио

Адаптивная главная страница на Astro, CSS и небольшом количестве JavaScript. Визуальная основа — утверждённый макет «Визуал версия 1».

## Локально

```sh
pnpm install
pnpm dev
pnpm build
```

После сборки статический сайт находится в `dist/`.

## Cloudflare Pages

Подключите этот GitHub-репозиторий в **Workers & Pages → Create application → Pages → Import an existing Git repository**. Выберите ветку `main`, команду сборки `pnpm build` и каталог результата `dist`. В настройках сборки задайте переменную окружения `PNPM_VERSION=11.19.0`; версия Node.js закреплена в `.node-version`.
