# NPC Dandelion — портфолио

Адаптивная главная страница на Astro, CSS и небольшом количестве JavaScript. Визуальная основа — утверждённый макет «Визуал версия 1».

## Локально

```sh
pnpm install
pnpm dev
pnpm build
```

После сборки статический сайт находится в `dist/`.

## Cloudflare Pages

Подключите этот GitHub-репозиторий в **Workers & Pages → Create application → Pages → Import an existing Git repository**. Выберите ветку `main`, команду сборки `pnpm build` и каталог результата `dist`. В настройках сборки задайте переменную окружения `PNPM_VERSION=11.19.0`; версия Node.js закреплена в `.node-version`.

## Материалы

- Лист одуванчика взят из предоставленного логотипа NPC Dandelion.
- Графика первого экрана извлечена из утверждённого визуала. Это превью, поэтому для финальной публикации желательно заменить его исходником высокого разрешения.
- Полный кейс NOIR COFFEE опубликован по адресу `/projects/noir-coffee/`: логотип, правила использования, визуальная система, визитка и униформа.
- Материалы NOIR обновлены по исправленному PDF: белый логотип и печать, адрес «Сочи, ул. Воровского, 153». Мокапы помечены как ИИ-визуализации.
- Исправленный PDF доступен для скачивания: `/downloads/NOIR-COFFEE.pdf` (14 страниц, около 8 МБ). Он загружается только по ссылке, не при открытии страницы.
- Фотографии и графика кейса подготовлены в WebP; шрифт Cruinn загружается локально. Автор Cruinn: Дмитрий Антонов / Blue Curve Designstudio; условия в `public/fonts/cruinn/readme.txt`.
- Авторские иллюстрации взяты из материалов проекта.
- Для остальных кейсов пока стоят явно подписанные заглушки; они не изображают готовые работы.

Изображения лежат в `public/assets/`, содержимое страницы — в `src/pages/index.astro`, оформление — в `src/styles/global.css`.

Страница кейса — `src/pages/projects/noir-coffee.astro`, её стили — `src/styles/noir-case.css`, изображения — `public/assets/noir/`. Настройки Cloudflare Pages остаются прежними: `pnpm build`, каталог `dist`, ветка `main`.
